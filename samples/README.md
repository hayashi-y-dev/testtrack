# Excelファイル見本

デモで「ファイル読込」を試すための見本です。ファイルを開き、右上の「Download raw file」からダウンロードして使ってください。\
読み込んだデータは、翌朝のデモデータのリセットで元に戻ります。\
山田さん（`yamada@example.com`）でログインし、最初に開く「ECサイトリニューアル」で読み込むと、下の表のとおりになります。

## 1_正常に読み込める

| ファイル | 確認画面での表示 | 確かめられること |
|---|---|---|
| 会員登録機能テスト.xlsx | 更新（53.3% → 86.7%） | 同じ名前のファイルがすでにあるため「更新」になり、進捗の変化と最終更新者を確かめてから実行できます |
| マイページ機能テスト.xlsx | 新規（62.5%） | 表紙・更新履歴・テストケースの3シートのうち、テストケースのシートだけを集計します |
| ポイント機能テスト_2画面.xlsx | 新規（71.4%） | テストケースのシートが2つあり、件数を合算します |
| 配送状況確認テスト_旧形式.xls | 新規（50%） | 旧形式（.xls）も読み込めます |
| 対象外のみ_ギフト機能テスト.xlsx | 新規（—） | すべて対象外（「-」）のため、進捗率は「—」になります |

## 2_エラーになる

| ファイル | 表示されるエラー |
|---|---|
| エラー_No列なし.xlsx | テストケースシート（「No」列と結果列を持つシート）が見つかりませんでした。 |
| エラー_テストケース0件.xlsx | 有効なテストケースが見つかりませんでした。 |
| エラー_Excel以外のファイル.txt | 対応していないファイル形式です。.xlsxまたは.xls形式のファイルを選択してください。 |

## 3_まとめて試す（部分成功）

正常なファイル2件とエラーのファイル1件が入っています（1・2のフォルダと同じファイルです）。\
3件をまとめて選ぶと、「エラーの1件はスキップされ、正常な2件のみ読み込まれます。」と表示され、正常な2件だけを読み込めます。

## ほかの試し方

- 楽観ロックを試すには、ブラウザのタブを2つ開き、両方で「会員登録機能テスト.xlsx」を確認画面まで進めます。片方で実行したあとにもう片方で実行すると、そのファイルは「確認後に別ユーザーによって更新された」というエラーになります。
- 登録取消を試すには、新しく読み込んだファイル（更新していないもの）の行の「︙」から、登録を取り消します。
